## Observação sobre performance

A home preserva o projeto visual original e, por compatibilidade, mantém o Tailwind via CDN. As novas páginas SEO usam CSS local e leve. A próxima otimização de performance deve ser orientada pelos dados reais de Core Web Vitals após publicação, evitando alterar visual ou comportamento sem evidência de gargalo.

## Observação sobre ranking

A versão corrige a base técnica e cria arquitetura e conteúdo para competir por múltiplas intenções de busca. Nenhuma implementação técnica pode garantir posição 1, volume de tráfego ou prazo de ranking; a evolução depende também de concorrência, autoridade, menções/backlinks, demanda, comportamento de busca, qualidade dos cases e sinais observados após indexação.
